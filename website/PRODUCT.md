# 轻点官网

## Platform

web

## 受众与目标

用户已确认：面向普通 Android 用户，以了解功能、体验演示和下载 APK 为主，GitHub 源码为辅助入口。页面中文，先本地审阅，满意后才发布。

## 产品事实

产品事实继承 ../PRODUCT.md 与 ../README.md：Android 8.0+、单点或最多 10 点顺序点击、可配置节奏和结束条件、悬浮控制。当前版本 1.0.4，APK 为 41,775 字节。无广告、不联网，不读取窗口内容。不给出游戏免检测或免处罚的承诺。

## 品牌与场景

延续应用的 #2458BD 蓝色、冷白背景、浅蓝分组面与圆角控制。访客在日常明亮环境中，用手机或电脑评估一个小工具，因此使用清晰明亮的页面和实际产品证据。

## 约束

- 网站与 Android 工程分目录，保留现有应用实现。
- 静态页面、相对资源路径，后续可部署到 GitHub Pages 项目子路径。
- 演示明确标为网页模拟，只处理网页内状态，不模拟设备控制能力。
- 不虚构用户量、评价、下载量或性能指标。
- 页面与部署内容在用户确认前不提交或推送到 GitHub。
